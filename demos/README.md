## What changes with the repo

A plain chat gives sensible general advice. On the agency numbers it even picks the same first fix. The difference:

- **Specific rules instead of general tips.** For example: book within four days at most, same or next day by default; read the script out loud 25 times a day; pay setters and closers on closes; split on-target pay 50/50 and work out a flat rate per sale.
- **A source for every rule.** Each line links to the minute of Hormozi's training, so you can check it.
- **No made-up benchmarks.** The plain chat gives ranges like "a decent show rate is 65% to 75%" with no source. The repo uses only the course's numbers, labels them as Hormozi's team's numbers, and does the math with yours.
- **Hormozi's order of work.** The script and frame come before the hire. Prove the process before you add a person. One fix at a time.
